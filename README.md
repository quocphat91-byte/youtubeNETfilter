# youtubeNETfilter

A high-performance YouTube search and filtering utility built with .NET.

## Features
- Fast YouTube content filtering.
- Configurable search parameters and duration filters.
- Lightweight and easy to integrate.

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/quocphat91-byte/youtubeNETfilter.git
   ```
2. Open the solution file `src/youtubeNETfilter.sln` in Visual Studio or VS Code.
3. Run the project:
   ```bash
   dotnet run --project src/youtubeNETfilter/youtubeNETfilter.csproj
   ```
